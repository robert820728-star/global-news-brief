# 事件類型與驗證來源

## 來源權重

依下列因素加權，不使用固定網站排名取代判斷：

1. 是否為資料或說法的原始產生者。
2. 是否具備該事件的專業能力與法定職責。
3. 是否提供可檢查的文件、方法、數據、影像或具名採訪。
4. 是否與其他來源真正獨立。
5. 是否接近事件現場與最新時間。
6. 是否有直接利益、宣傳目的、審查限制或責任風險。

## 類型路由

| 事件類型 | 優先來源 | 必查重點 | 注意事項 |
|---|---|---|---|
| 颱風、豪雨、熱浪、寒潮 | 主要影響地區官方氣象與防災單位、世界氣象組織、主要媒體現場 | 路徑、雨量、警戒、發布時間、影響區 | 依事件階段切換所在地官方來源，不固定只查台灣。 |
| 地震、海嘯、火山 | 當地地震監測機構、美國地質調查局、海嘯警報中心、地方災防及通訊社 | 震央、規模、深度、震度、警戒、傷亡截止時間 | 不同機構規模可因算法與修訂時間不同，應並列版本。 |
| 疫情、公衛 | 當地衛生部門、世界衛生組織、非洲／歐洲疾控機構、醫療現場、研究或專家 | 病例定義、確診、死亡、疫區、統計截止、檢測能力 | 官方數字可作已確認基準，但需評估低報、延遲與政治限制。 |
| 戰爭、軍事、恐攻 | 衝突各方聲明、聯合國、主要通訊社、可信開源情報、人權或救援組織 | 時間線、地點、傷亡、戰果、歸因、影像定位 | 任一交戰方的戰果與責任說法都不能單獨當結論。 |
| 政策、法律、監管 | 法規原文、主管機關、法院、提案方、反對方、受影響團體、法律專家 | 正式文本、適用對象、生效時間、執行方式 | 媒體標題不得取代法條與正式決定。 |
| 經濟、金融、公司 | 交易所、財報、監管文件、央行、統計局、公司公告、產業與市場分析 | 金額、期間、會計口徑、控制權、政策內容 | 公司前景與管理層說法屬公司立場，數字以原始文件為準。 |
| 科技、資安 | 原始研究、技術報告、漏洞公告、受影響機構、監管或資安應變中心、獨立專家 | 技術方法、受影響版本、利用狀態、歸因可信度 | 廠商行銷與攻擊歸因要與可檢查證據分開。 |
| 災害、公共安全 | 消防、警政、地方政府、醫院、救援單位、通訊社與當地媒體 | 傷亡、失蹤、撤離、交通、停電、災損截止 | 數字快速變動，必須標示時間；現場照不能證明整體規模。 |
| 文化、平台、遊戲、電競 | 官方規則、平台公告、主辦單位、產業媒體、創作者／選手／工會或受影響者 | 規則變動、收入、適用範圍、產業影響 | 不把宣傳稿或粉絲聲量當成制度影響證據。 |
| 科研、自然史 | 論文、資料庫、研究機構、同行專家、期刊更正或撤稿 | 研究方法、樣本、限制、是否經同行審查 | 新奇不等於已證實；新聞稿不能取代論文內容。 |

## 多角度最低要求

多角度不是固定列四方，而是回答事件真正存在的爭點：

- 客觀資料由誰測量。
- 行動或決策由誰做出。
- 誰受到影響。
- 誰質疑數字、責任或效果。
- 哪個第三方能獨立評估。

沒有實質分歧時省略讀者版「各方說法」，但證據台帳仍需保存來源角色。
